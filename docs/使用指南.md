# 使用指南

## 安装

Python 3.10–3.12。在项目根执行：

```bash
python -m pip install -e '.[deep,gbdt,test]'
```

`deep` 安装 PyTorch，`gbdt` 安装 LightGBM。没装 PyTorch 时，非神经网络模型照常可用。项目根需要有 `configs/`；数据集写到 `data/datasets/`，结果写到 `results/`。在别的目录运行时用 `--root <项目根>` 指定，或设环境变量 `WPF_BENCHMARK_ROOT`。

## 命令

| 命令 | 作用 |
|---|---|
| `wpf-benchmark datasets` | 列出数据集及构建状态 |
| `wpf-benchmark build <数据集> [-o key=value ...]` | 从原始文件构建数据集 |
| `wpf-benchmark tasks` | 列出任务，检查与数据集是否匹配 |
| `wpf-benchmark models` | 列出模型及默认参数 |
| `wpf-benchmark run --task T --model M [--seed k] [--save-predictions]` | 单次运行 |
| `wpf-benchmark score --task T --predictions p.npz --out 目录` | 给外部预测打分 |
| `wpf-benchmark study --plan P [--preflight / --package / --only 文本]` | 批跑 |

`--model` 可以是注册名（用默认参数）、`configs/models/` 下的配置名，或一个 JSON 路径。

## 构建数据集

```bash
wpf-benchmark build sdwpf                                    # 原始 CSV 在 data/raw/sdwpf/
wpf-benchmark build sdwpf -o mode=legacy_clean -o clean_parquet=<旧 sdwpf_clean.parquet>
wpf-benchmark build kelmarsh -o source=<02_Kelmarsh_UK 目录>
wpf-benchmark build penmanshiel -o source=<03_Penmanshiel_UK 目录>
wpf-benchmark build synthetic
```

两种 SDWPF 构建方式得到的数据逐格相同。K/P 的原始压缩包有十几 GB，不进入服务器同步；在本地构建后，把 `data/datasets/kelmarsh/`、`penmanshiel/` 两个目录直接拷到服务器（见[服务器部署与批跑](服务器部署与批跑.md)）。

## 新增一个数据集

1. 在 `src/wpf_benchmark/datasets/` 写 `<名称>.py`，提供 `build(paths, name, **options) -> (Panel, report_md)`。`synthetic.py` 是最小范例。
2. 在 `datasets/__init__.py` 的 `ADAPTERS` 里登记。
3. 元数据字段、时间约定和掩码写法见[平台接口](平台接口.md)第 2 节。每个掩码都要写明它对应哪个真值变量。
4. 在 `configs/tasks/` 写任务 JSON。

## 新增一个模型

1. 非神经网络：继承 `models.base.Forecaster`，实现 `fit` 和 `predict`。神经网络：继承 `models.neural.NeuralForecaster`，设 `layout`，实现 `build_network`；训练循环、早停和检查点不用写。
2. 用 `@register_model("名称")` 注册，并在 `models/__init__.py` 里导入模块。不要在模块顶层导入 torch 或 lightgbm。
3. 在 `configs/models/` 写参数 JSON，在 `tests/` 加测试，在[模型](模型.md)里写一节。

## 测试

```bash
python -m pytest -q
```

测试只用合成数据和手造的小文件，CPU 上约 1 分钟。
